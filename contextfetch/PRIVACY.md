# Privacy Policy

The ContextFetch plugin does not collect, store or log any user data itself.

When a tool runs, the plugin sends the tool inputs (search query, domain filters, date filter, page URLs and highlights query) and your ContextFetch API key to the ContextFetch API at `https://api.contextfetch.dev` over HTTPS, and returns the API response to Dify. No other data is sent and no other third party is contacted.

The API key is stored by Dify as an encrypted secret credential, not by the plugin.

How ContextFetch handles requests it receives is described at https://contextfetch.dev. Questions: hello@contextfetch.dev.
